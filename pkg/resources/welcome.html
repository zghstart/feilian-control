飞连控制

这个安装包会安装：

  • 一个菜单栏 App“飞连控制”
  • 一个只接受“停用 / 恢复”固定命令和只读健康检查的 root 助手
  • 命令行工具 feilianctl

安装时输入一次管理员密码。之后日常停用 / 恢复不再需要密码，默认也不弹 Touch ID。

未签名提示：当前安装包没有 Apple Developer ID 签名和公证。如果 macOS 提示无法验证开发者，请右键点击安装包 → 打开；或在终端运行：

sudo installer -pkg ~/Downloads/FeiLianControl-*.pkg -target /

安装完成后，打开“飞连控制.app”，菜单栏会出现盾牌图标。点击图标即可停用全部后台、仅退出界面，或恢复飞连；需要时可在菜单中开启“登录时自动启动”。

如遇问题，可点击“故障诊断…”，或在终端运行 feilianctl doctor。这些检查不会修改飞连状态。

请只在你有权管理的设备上使用。停用企业安全客户端可能违反公司 IT / BYOD 政策。
